## 실습 규칙

1. 각 팀은 배정된 팀 폴더 안에서만 작업합니다.
2. `main` 브랜치에서 직접 작업하지 않습니다.
3. 작업 전 개인 브랜치를 생성합니다.
   - 브랜치명: `feat/teamXX-name`
   - 예시: `feat/team00-gildong`
4. 개인 파일(코드, 마크다운, 메모 등)을 추가하고, 팀 `README.md`에 소개와 파일 링크를 정리합니다.
5. 작업이 끝나면 Pull Request(PR)를 생성합니다.
6. PR 본문에 `Closes #이슈번호`를 작성하여 팀 이슈를 연결합니다.
7. PR은 작성자 본인을 제외한 팀원 1명 이상의 승인을 받은 뒤 병합합니다.
8. 다른 팀의 파일은 수정하지 않습니다.

충돌이 발생하면 팀원과 함께 직접 해결해 봅시다!
